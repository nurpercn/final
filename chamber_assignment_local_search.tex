After the chamber configurations are determined, as a second step we implement a local search phase to fine-tune the chamber configuration decisions. We use the scheduling procedure to form a schedule of the tests according to the given chamber configurations and the sample-size vector. Then, we determine the normalized workload of each chamber by dividing the total duration of the tests assigned to that chamber by the total number of stations in that chamber. A chamber is \emph{highly loaded} if its normalized workload is large and \emph{lightly loaded} if its normalized workload is small. The normalized workload of chamber \(c\) is
\begin{equation}
\label{eq:chamber_load}
\lambda_c=\frac{B_c}{K_c}.
\end{equation}
More specifically, we consider exchanging the configurations of a highly loaded chamber and a lightly loaded chamber with \(\lambda_c>\lambda_{c'}\) (without violating \eqref{eq:assign_one}--\eqref{eq:assign_hum}). For each of these possible local moves, we use the scheduling procedure to determine the schedule and observe the effect of such a local move on the total tardiness. We update the chamber configuration assignment if the solution improves. Then, if no such swap improves the solution, we consider reassigning a lightly loaded chamber to the configuration of a highly loaded chamber. If such a move improves the solution, we update it. These two local search moves (exchanging the configurations of two chambers and reassigning a lightly loaded chamber to the configuration of a highly loaded chamber) are implemented sequentially as long as the solution improves, or until \(B_{\mathrm{room}}\) calls of the scheduling procedure have been used. The steps of the local search procedure for improving the chamber configuration decisions are provided in Algorithm~\ref{alg:chamber_assignment}.

\begin{algorithm}[H]
\caption{\textsc{ChamberAssignment}()}
\label{alg:chamber_assignment}
\begin{algorithmic}[1]
\State \textbf{Input:} sample-size vector \(\mathbf{s}\)
\State \textbf{Output:} an improved chamber configuration assignment \(\mathbf{x}\)
\State \(\mathbf{x}\leftarrow\Call{MIP-CCD}{\mathbf{s}}\) \label{step:ca-exact}
\State \((\Pi,T^{tot})\leftarrow\Call{Schedule}{\mathbf{x},\mathbf{s}}\) \label{step:ca-eval}
\Repeat
    \State \(\lambda_c\leftarrow B_c/K_c\) for all \(c\in\mathcal{C}\) using \(\Pi\) \label{step:ca-load}
    \State \(\mathit{improved}\leftarrow\mathrm{false}\)
    \For{pairs \((c,c')\) with \(\lambda_c>\lambda_{c'}\)} \label{step:ca-loop1}
        \State \(\mathbf{x}_{cand}\leftarrow\Call{Swap}{\mathbf{x},c,c'}\) \Comment{exchange the configurations of \(c\) and \(c'\)} \label{step:ca-swap}
        \If{\(\mathbf{x}_{cand}\) satisfies \eqref{eq:assign_one}--\eqref{eq:assign_hum}}
            \State \((\Pi_{cand},T^{tot}_{cand})\leftarrow\Call{Schedule}{\mathbf{x}_{cand},\mathbf{s}}\) \label{step:ca-nbhd}
            \If{\((T^{tot},\mathbf{1}^{\mathsf{T}}\mathbf{s})\succ_{\mathrm{lex}}(T^{tot}_{cand},\mathbf{1}^{\mathsf{T}}\mathbf{s})\)}
                \State \((\mathbf{x},\Pi,T^{tot})\leftarrow(\mathbf{x}_{cand},\Pi_{cand},T^{tot}_{cand})\) \label{step:ca-accept}
                \State \(\mathit{improved}\leftarrow\mathrm{true}\); \textbf{break} \label{step:ca-loop1.5}
            \EndIf
        \EndIf
    \EndFor \label{step:ca-loop2}
    \If{\(\mathit{improved}=\mathrm{false}\)}
        \For{pairs \((c,c')\) with \(\lambda_c>\lambda_{c'}\)}
            \State \(\mathbf{x}_{cand}\leftarrow\Call{Move}{\mathbf{x},c,c'}\) \Comment{assign \(c'\) to the configuration of \(c\)} \label{step:ca-move}
            \If{\(\mathbf{x}_{cand}\) satisfies \eqref{eq:assign_one}--\eqref{eq:assign_hum}}
                \State \((\Pi_{cand},T^{tot}_{cand})\leftarrow\Call{Schedule}{\mathbf{x}_{cand},\mathbf{s}}\) \label{step:ca-move2}
                \If{\((T^{tot},\mathbf{1}^{\mathsf{T}}\mathbf{s})\succ_{\mathrm{lex}}(T^{tot}_{cand},\mathbf{1}^{\mathsf{T}}\mathbf{s})\)}
                    \State \((\mathbf{x},\Pi,T^{tot})\leftarrow(\mathbf{x}_{cand},\Pi_{cand},T^{tot}_{cand})\) \label{step:ca-move3}
                    \State \(\mathit{improved}\leftarrow\mathrm{true}\); \textbf{break}
                \EndIf
            \EndIf
        \EndFor
    \EndIf
\Until{\(\mathit{improved}=\mathrm{false}\) or \(B_{\mathrm{room}}\) calls of \(\textsc{Schedule}()\)} \label{step:ca-stop}
\State \Return \(\mathbf{x}\)
\end{algorithmic}
\end{algorithm}

In Algorithm~\ref{alg:chamber_assignment}, we start with a chamber configuration assignment determined by MIP-CCD(\(\mathbf{s}\)) and a schedule determined for that assignment (Steps~\ref{step:ca-exact}--\ref{step:ca-eval}). Then, we compute the normalized workload of each chamber (Step~\ref{step:ca-load}) and check whether exchanging the configurations of a highly loaded chamber and a lightly loaded chamber improves the current solution (Steps~\ref{step:ca-loop1}--\ref{step:ca-loop2}). For each such feasible move we call the scheduling procedure (Step~\ref{step:ca-nbhd}). We then update the current solution if that move improves it under the lexicographic test (Steps~\ref{step:ca-accept}--\ref{step:ca-loop1.5}). Next, if no swap is accepted, a lightly loaded chamber is reassigned to the configuration of a highly loaded chamber (Step~\ref{step:ca-move}). For each such feasible move we call the scheduling procedure (Step~\ref{step:ca-move2}). If the new schedule after this step is better than the current one, the current solution is updated (Step~\ref{step:ca-move3}). The two moves are repeated until a pass yields no improvement or \(B_{\mathrm{room}}\) calls of \(\textsc{Schedule}()\) have been used.
