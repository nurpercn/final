## 4. Görüşmede söyleyecekleriniz (Safety Compliance)

### NIBE neden uygun
NIBE ısı pompası, sıcak su, havalandırma ve sürdürülebilir iklim çözümleri üretiyor. Vestel’deki soğutma / IEC 60335 / CE / LVD deneyiminiz bu ürüne yakın. Rol İsveççe şartı yazmıyor; İngilizce zorunlu.

### Güçlü köprüler
| İlan | Sizin kanıtınız |
|---|---|
| LVD, CE marking | Vestel CE/LVD; 100+ ülke, ~500 proje/yıl |
| IEC 60335 (ısı pompası / aksesuar) | IEC 60335-1 ve 60335-2-24 (soğutma). Aynı seri; 2-40’a geçiş: elektriksel güvenlik + soğutucu / yanıcı gaz mantığı |
| Test koordinasyonu, harici laboratuvar | SGS, UL, Intertek, TÜV ile sertifikasyon ve test |
| Teknik dokümantasyon | Teknik dosya, DoC, sertifikasyon kayıtları |
| R&D ile lifecycle | Functional Lead, Non-EU Cooling Design & Certification |
| Standardizasyon | IEC TC61 ve APPLiA çalışma grupları |
| Eğitim / rehberlik | Çok disiplinli ekiplere regülasyonun pratik aksiyona çevrilmesi |

### Açıkça iddia etmeyin
- PED uzmanlığı (basınçlı ekipman direktifi CV’de yok)
- Markaryd laboratuvarında hands-on test operatörlüğü
- İsveççe
- IEC 60335-2-40’ı halihazırda günlük uyguladığınız

### 2-40’ı nasıl konuşun
“I work daily with IEC 60335 for refrigeration appliances, including electrical safety and refrigerant-related requirements. I have not yet owned EN 60335-2-40 as my primary standard, but the structure — essential safety, testing with labs, technical file and CE marking — is the same process I already lead. I would close the heat-pump-specific clauses quickly with the Markaryd team.”

### Beklenen sorular
1. Why NIBE / why heat pumps? → sürdürülebilir ısıtma; cooling background; CE + 60335.
2. Walk me through CE marking for a new platform. → requirements → gap analysis → test plan → lab → technical file → DoC → market release; change control.
3. LVD vs RED vs MD? → LVD: elektriksel güvenlik (sizin çekirdeğiniz). RED: kablosuz/connected ürünler. MD: makine güvenliği; ısı pompasında sistem sınırına göre. Abartmadan, öğrenme isteğiyle.
4. How do you work with external labs? → scope, quotation, protocol, non-conformity close-out, certificate follow-up.
5. A product fails a safety test close to launch. What do you do? → stop/contain, root cause with R&D, retest evidence, do not ship on hope.
6. Work permit / relocation? → İzmir’den taşınmaya hazır; İsveç çalışma izni için şirket sponsorluğuna ihtiyacınız var. Net ve kısa söyleyin.
7. PED rolü çıkarsa? → elektriksel güvenlik, CE, test koordinasyonu güçlü; PED’i NIBE’de öğrenmeye açık olduğunuzu, asıl derinliğinizin Safety Compliance olduğunu söyleyin.
